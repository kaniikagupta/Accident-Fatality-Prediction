
# Accident Fatality Prediction

## Overview
This project predicts accident fatality severity using machine learning techniques and real-world crash datasets.

## Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Accident severity prediction
- Interactive Streamlit dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- LightGBM
- Streamlit
- Plotly

## Project Structure

```text
app.py
data/
code/
assets/
model/
```

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dataset

Road accident datasets containing driver, vehicle, weather and crash-related attributes.
